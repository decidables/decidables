# [<b>dab’le</b>](https://decidables.github.io/dable)<br>Dabble with Explorable Explanations of Decision Making

The website for [<b>dab’le</b>](https://decidables.github.io/dable) which has quick takes so you
can dabble with the individual explorables that make up
[<b>decidables</b>](https://decidables.github.io), without committing to the full explanations.

### Features/Bugs/Notes

### Package Scripts

- `yarn clean`
  - Cleans site by deleting `local/`, `dist/`, and associated directory in `decidables.github.io`
- `yarn lint`
  - Lints markdown, scripts, and styles in `src/`
- `yarn develop`
  - Makes project from `src/` to `local/` while pulling in dependencies
- `yarn watch`
  - Executes `develop` on file changes in `src/` or local package dependencies `../<library>/src/`
- `yarn build`
  - Makes optimized project from `src/` to `dist/`
- `yarn deploy`
  - Re-build markdown (to grab new version) then copies files from `dist/` to top level
    server directory `decidables.github.io`
- `yarn serve`
  - Runs a basic http server, to serve `decidables/` (e.g. <http://localhost:8000/local/> or
    <http://localhost:8000/dist/>)
